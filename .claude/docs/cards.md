## Canva cutout pipeline

- Canva cutout pipeline — **CLASSICS DONE (2026-07-21): all 54 classics exported, bg-removed, pre-named as `card-lab/canva/cl<N>-top.png` / `cl<N>-bottom.png` (vault)** (107 files; cl54-bottom missing — that photo was never taken, re-shoot the teal board's underside). The winning flow (repeat per collection): (1) Canva **Sheet** with columns name/size/top/bottom, one board per row, bg-removed images in the cells; (2) name the sheet after the collection (design titles inherit it); (3) sidebar **Bulk create** → data range incl. header row → pick `classics-card-template` (2000×1500, two images, NO text element — a text layer bakes into the export and pollutes the cutouts, learned the hard way) → auto-match → generates one design per row titled `(Bulk N) <sheet-name>`; (4) `search-designs` for those titles (paginate, ~25/call), `export-design` each `{png, transparent_background, lossless}`, curl down; (5) local script slices each card L/R and keeps the largest connected alpha component per half (scipy `ndimage.label` — this also strips any stray marks), crops to bbox, writes `cl<N>-top/bottom.png`. Row order = board order = names, so **no pixel-matcher naming step needed** — batch-review.html (vault) is now only for the legacy `batch1-pNN.png` files (superseded for classics, ignorable). ## Real board dims — DIMS_MM (2026-08-13)

The dims machinery finally eats real data. `DIMS_MM` in index.html (beside `PH_DIMS`) is the hand-authored source of truth: keyed by PADDED inventory ref, value `[width, length, tailWidth, noseWidth]` in mm, tail/nose optional (HS 10/15/18 have none — Dylan measured no parens for those). Width is the widest point; the parens in his 2026-08-13 message were "width at tail, width at nose". `dimsStr()` derives the card string (`32.4 × 95 MM`); `jmeta.dimsPh` is now `dimsStr(DIMS_MM[ref]) || PH_DIMS[ref] || ""`, so the hover name→dims decode (`data-dims` via `nmt`) fires with real numbers on all 14 hand-shaped boards. The card decode stays width × length ONLY — tail/nose were "too much noise on a card decode" (his words); the full line lives in the lightbox (`#lb-dims`, see lightbox.md). `PH_DIMS` shrank to `OG 01` only (HS 01's placeholder retired when its real row landed) — it remains a card-decode demo and NEVER prints in the lb.
