## The recipe (design-bundle/, gitignored)

- `design-bundle/build_cards.py` — assembles every component card: `@dsCard` marker + the page's full `<style>` block (`page-css-fragment.css`, lines 10–4410 of k-home-dual.html — NOT 10–4744; the style block ends at 4411 and the page markup follows, bitten once) + a frozen specimen + a small seat CSS. Re-run per card name after re-freezing a specimen.
- `design-bundle/specimens/` — rendered-DOM freezes taken from the live page in REAL Chrome (the pane's rAF was dead again that day): collection scard, settled lightbox (`#lb.fv3.in` at 1440×900), locked-open bay (`bay locked inked pulled fullish shadowed`, opened via `#bar-script` click — synthetic chip-adds land but the drawer drains; the deck-mark toggle is the reliable door), mobile YOUR PICKS (topbar + colpage at 393), desktop topbar/gpick fragments.
- Freezes carry their geometry inline, so each card's registered viewport must MATCH its extraction viewport.
- **Body attributes are load-bearing on frozen markup**: `data-lb="deck"` gates the lb header/strip/flankers (`body[data-lb="deck"] #lb.fv3 …`), `data-card="framev3"` gates the whole bay (`body:not([data-card="framev3"]) .bay { display:none }`), and the bay's desktop rules die under 941px — a bay card needs a ≥941 viewport.
- The decode + buttons cards carry lifted JS (decodeInto/wantWord/cardDressOn·Off, chip aim, DM glitch, organ `.on` toggle — the engulf is class-driven, not `:hover`). The decode card autoplays via `.hold` (the CSS hover mirror).
- Pages upload as `redesign/home-{desktop,mobile}.html` so their page-relative `card-lab/…` refs resolve; components sit one level deep (`components/…`) so their `../site`/`../redesign` refs resolve. Local preview parity via symlinks inside design-bundle (`redesign`, `site`, `videos`, and `pages/card-lab`, `pages/media`).
- DesignSync mechanics: `finalize_plan` requires an explicit `deletes: []`; `write_files` bodies cap somewhere under ~64MB raw — 18MB batches upload cleanly (9 calls for the full set).
- Chrome-driving gotcha: Dylan's Chrome zooms localhost at 175%, so `emulate viewport` must be ×1.75 to land a true CSS size on DESKTOP tabs (mobile emulation is exempt). The chrome-devtools MCP attaches to his real profile — do state-changing extraction in an `isolatedContext` so his localStorage (ground pick, lisst) is never touched.
