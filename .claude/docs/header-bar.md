## THE SCROLL RELAY (2026-08-14) — the bar word is where you've been

**The header vision's centrepiece, built the same day the drop finished — the direct descendant of the parked `?colbar=` rail ("this type of scroll IS the move", 2026-08-08): the fixed window with names swapping inside is now the BAR'S OWN CENTRE SLOT, no second bar.** Colpage-only (every collection route + shop-all stacks all sections in one scroll — the structure was already right); **the HOME BANDS DO NOT RELAY, Dylan's explicit rule: "the home page only has one row of cards per section and doesn't get the collections page header scroll treatment"** — home always reads COLLECTIONS.
